2. USING FEEDBACK SYSTEM TO COLLECT TRAINING DATA
═══════════════════════════════════════════════════════════════════════════════

The system NOW includes a CONFIDENCE THRESHOLD that automatically flags weak 
predictions and requests correction feedback.

WHAT HAPPENS:
──────────────

1️⃣  USER UPLOADS IMAGE
2️⃣  MODEL PREDICTS (e.g., "organic 54%")
3️⃣  SYSTEM CHECKS: Confidence < 70%? 
4️⃣  IF YES → Shows ⚠️ WARNING + 🔴 "REPORT ERROR" BUTTON
5️⃣  USER CLICKS & SELECTS CORRECT LABEL (e.g., "plastic")
6️⃣  FEEDBACK SAVED TO DATABASE
7️⃣  DATA READY FOR MODEL RETRAINING

DATA STRUCTURE (in database feedback table):
────────────────────────────────────────────

{
  "prediction_id": 128,           # Which prediction was wrong
  "image_id": 42,                 # Which image was used
  "predicted_category": "organic", # What model said
  "corrected_category": "plastic", # What user corrected to
  "confidence": 0.54,             # Model's confidence score
  "notes": "This is a plastic bottle",  # User note
  "timestamp": "2026-04-16T18:41:00Z"  # When submitted
}

3. COLLECTING FEEDBACK DATA (3-Step Process)
═══════════════════════════════════════════════════════════════════════════════

Step 1: Generate Test Cases (Manual)
──────────────────────────────────────

Upload 20-50 test images covering:
  ✅ Plastic bottles, bags, containers (common misclassifications)
  ✅ Metal cans, foil (similarity confusion)
  ✅ Glass bottles, jars
  ✅ Paper, cardboard
  ✅ Various E-waste types
  ✅ Organic items, food

For EACH prediction:
  - If confidence < 70%, submit correction
  - Add notes explaining what was wrong
  - This creates training examples


Step 2: Export Feedback Data
──────────────────────────────

Run SQL query to extract all feedback:

  sqlite3 backend/data/database/wastehandling.db

  SELECT 
    f.predicted_category,
    f.corrected_category,
    f.confidence,
    f.notes,
    p.image_path
  FROM feedback f
  LEFT JOIN prediction p ON f.prediction_id = p.id
  ORDER BY f.timestamp DESC;

Export as CSV:

  .mode csv
  .output feedback_corrections.csv
  SELECT ... (query above)
  .quit

────────────────────────────────

Create folder structure:

  training_data/

  ├── metal/

4. RETRAINING THE MODEL (3 Options)
═══════════════════════════════════════════════════════════════════════════════

OPTION A: Fine-tune Existing Model (RECOMMENDED)
──────────────────────────────────────────────────

Faster, uses existing model as base, learns from correction data.

Code (Python):

  import tensorflow as tf
  from tensorflow.keras import layers
  from PIL import Image
  import numpy as np
  from pathlib import Path

  # Load pre-trained model
  model = tf.keras.models.load_model('backend/best_model.h5')

  # Freeze early layers (keep learned features)
  for layer in model.layers[:-20]:
      layer.trainable = False

  # Load training images
  training_data = []
  training_labels = []

  class_names = ['Battery', 'Keyboard', ..., 'trash']  # Your 17 classes

  data_dir = Path('training_data')
  for idx, class_name in enumerate(class_names):
      class_dir = data_dir / class_name
      if class_dir.exists():
          for img_path in class_dir.glob('*.jpg'):
              img = Image.open(img_path).convert('RGB')
              img = img.resize((224, 224))
              training_data.append(np.array(img) / 255.0)
              training_labels.append(idx)

  # Convert to numpy arrays
  X_train = np.array(training_data)
  y_train = np.array(training_labels)

  # Compile model
  model.compile(
      optimizer=tf.keras.optimizers.Adam(learning_rate=0.0001),
      loss='sparse_categorical_crossentropy',
      metrics=['accuracy']
  )

  # Fine-tune on correction data
  history = model.fit(
      X_train, y_train,
      epochs=10,          # Adjust based on data size
      batch_size=16,
      validation_split=0.2,
      verbose=1
  )

  # Save improved model
  model.save('backend/best_model_v2.h5')

  print(f"Training complete!")
  print(f"Final accuracy: {history.history['accuracy'][-1]:.2%}")

6. CREATING TRAINING SCRIPT
═══════════════════════════════════════════════════════════════════════════════

Save as `retrain_model.py`:

  #!/usr/bin/env python3
  """Fine-tune waste classifier on user correction feedback"""

  import argparse
  import tensorflow as tf
  from tensorflow.keras import layers
  from PIL import Image
  import numpy as np
  from pathlib import Path
  import json

  def load_training_data(data_dir, target_size=(224, 224)):
      """Load images from organized class folders"""
      
      data_dir = Path(data_dir)
      X = []
      y = []
      
      # Get class names from class_names.json
      with open('backend/class_names.json') as f:
          class_names = json.load(f)
      
      print(f"Loading {len(class_names)} classes...")
      
      for idx, class_name in enumerate(class_names):
          class_dir = data_dir / class_name
          
          if not class_dir.exists():
              print(f"⚠️  {class_name} - no images found")
              continue
          
          images = list(class_dir.glob('*.jpg')) + list(class_dir.glob('*.jpeg'))
          
          for img_path in images:
              try:
                  img = Image.open(img_path).convert('RGB')
                  img = img.resize(target_size)
                  img_array = np.array(img) / 255.0
                  X.append(img_array)
                  y.append(idx)
              except Exception as e:
                  print(f"Error loading {img_path}: {e}")
          
          print(f"✓ {class_name}: {len(images)} images")
      
      return np.array(X), np.array(y), class_names

  def fine_tune_model(model_path, training_data_dir, epochs=15, output_path=None):
      """Fine-tune model on feedback corrections"""
      
      print("\n🔄 Loading pre-trained model...")
      model = tf.keras.models.load_model(model_path)
      
      print("📊 Loading training data...")
      X_train, y_train, class_names = load_training_data(training_data_dir)
      
      print(f"✓ Loaded {len(X_train)} training samples across {len(class_names)} classes")
      
      # Freeze early layers
      print("\n🔒 Freezing early layers...")
      for layer in model.layers[:-20]:
          layer.trainable = False
      
      # Compile
      print("⚙️  Compiling model...")
      model.compile(
          optimizer=tf.keras.optimizers.Adam(learning_rate=0.0001),
          loss='sparse_categorical_crossentropy',
          metrics=['accuracy']
      )
      
      # Train
      print("\n🚀 Training on corrections (this may take 2-4 hours)...")
      history = model.fit(
          X_train, y_train,
          epochs=epochs,
          batch_size=16,
          validation_split=0.2,
          verbose=1,
          callbacks=[
              tf.keras.callbacks.EarlyStopping(
                  monitor='val_accuracy',
                  patience=3,
                  restore_best_weights=True
              )
          ]
      )
      
      # Save
      if output_path is None:
          output_path = model_path.replace('.h5', '_improved.h5')
      
      model.save(output_path)
      
      # Report
      final_acc = history.history['accuracy'][-1]
      print(f"\n✅ Training complete!")
      print(f"📈 Final accuracy: {final_acc:.2%}")
      print(f"💾 Model saved: {output_path}")
      
      return model, history

  if __name__ == '__main__':
      parser = argparse.ArgumentParser()
      parser.add_argument('--model', required=True, help='Path to base model')
      parser.add_argument('--data', required=True, help='Training data directory')
      parser.add_argument('--epochs', type=int, default=15)
      parser.add_argument('--output', help='Output model path')
      
      args = parser.parse_args()
      fine_tune_model(args.model, args.data, args.epochs, args.output)

  # Usage:
  # python retrain_model.py --model backend/best_model.h5 --data training_data --output backend/best_model_v2.h5

8. ADVANCED: ENSEMBLE MODELS
═══════════════════════════════════════════════════════════════════════════════

For even higher accuracy (>95%), use multiple models:

Approach:
─────────

1. Train 3 models on slightly different data/architectures:
   ├─ Model A: MobileNetV2 (current)
   ├─ Model B: EfficientNet
   └─ Model C: ResNet50

2. On prediction, run all 3 models

3. Combine results (voting):
   ├─ All 3 agree → High confidence, use result
   ├─ 2 agree, 1 different → Medium confidence, flag for review
   └─ All different → Low confidence, manual review

Code:

  predictions = []
  predictions.append(model_a.predict(image))
  predictions.append(model_b.predict(image))
  predictions.append(model_c.predict(image))
  
  # Voting
  final_prediction = np.argmax(np.sum(predictions, axis=0))
  
  # Confidence
  vote_count = np.max(np.sum(predictions, axis=0))
  confidence = vote_count / 3  # 1/3 = 1 model, 3/3 = all 3 agree

9. AUTOMATED RETRAINING (Optional)
═══════════════════════════════════════════════════════════════════════════════

Set up weekly automatic retraining:

Create `auto_retrain.sh`:

  #!/bin/bash

  # Weekly retraining job

  echo "🔄 Starting auto-retrain at $(date)"

  # Export feedback
  sqlite3 backend/data/database/wastehandling.db \
    "SELECT image_path, corrected_category FROM feedback 
     WHERE timestamp > datetime('now', '-1 week')" \
    > /tmp/weekly_corrections.csv

  # Count corrections
  count=$(wc -l < /tmp/weekly_corrections.csv)
  if [ "$count" -lt 10 ]; then
    echo "⚠️  Only $count corrections - skipping retrain"
    exit 0
  fi

  echo "✅ Found $count new corrections - retraining..."

  # Organize and retrain
  python organize_training_data.py /tmp/weekly_corrections.csv
  python retrain_model.py \
    --model backend/best_model.h5 \
    --data training_data/ \
    --output backend/best_model_weekly.h5

  # Validate
  if python evaluate_model.py --model backend/best_model_weekly.h5; then
    cp backend/best_model.h5 backend/best_model_backup.h5
    cp backend/best_model_weekly.h5 backend/best_model.h5
    echo "✅ Model updated!"
  else
    echo "❌ Validation failed - keeping old model"
  fi

Schedule with cron (run every Sunday at 2 AM):

  0 2 * * 0 /path/to/auto_retrain.sh

10. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ Model accuracy not improving
  └─ Check: Do you have at least 30-50 new training examples?
  └─ Solution: Collect more correction data first

❌ Model performs worse after retraining
  └─ Cause: Overfitting on small dataset
  └─ Solution: Increase validation_split to 0.3, reduce epochs

❌ Out of memory during training
  └─ Solution: Reduce batch_size from 16 to 8
  └─ Or: Load data in smaller batches

❌ Can't export feedback from database
  └─ Check: sqlite3 installed? (pip install sqlite3)
  └─ Check: Database file exists at path shown in health endpoint
